# Нейросетевой расчет фазового ДОЭ для многоплоскостного формирования волнового фронта
> **Хакатон НИЯУ МИФИ «ИИ в фотонике» | Решение команды AI Photonics**

Программный комплекс на базе глубокой сверточной архитектуры **U-Net** и дифференцируемого физического слоя **дифракции Френеля** для сверхбыстрого и высокоточного синтеза фазового профиля дифракционного оптического элемента (ДОЭ), восстанавливающего заданные оптические распределения одновременно в 4 осевых плоскостях.

---

## 1. Архитектура и физическая модель

- **Нейросетевое ядро (U-Net)**:
  - 7.85 млн параметров с 4 уровнями кодирования и декодирования (128x128 $\to$ 64x64 $\to$ 32x32 $\to$ 16x16 $\to$ 8x8 в боттлнеке).
  - Глобальное рецептивное поле ($RF \ge 128 \times 128$), позволяющее модели учитывать нелокальный дифракционный вклад каждого пикселя.
  - Skip-connections для сохранения высокочастотных контуров и мелких деталей.
  - Выходной слой с проекцией $\tanh(x) \cdot \pi$, гарантирующий строгий физический диапазон фазы $[-\pi, +\pi]$.
- **Дифференцируемый физический слой (Single-FFT Fresnel)**:
  - Прямое моделирование дифракции Френеля на основе скалярной теории дифракции с одним быстрым преобразованием Фурье (БПФ) на плоскость.
  - Предрассчитанные фазовые буферы квадратичного чирпа.
  - Длина волны: $\lambda = 532$ нм (зеленый лазер).
  - Шаг сетки (пиксель ПВМС): $\Delta u = 10$ мкм.
  - Осевые расстояния: $z_1 = 24.1$ мм, $z_2 = 25.3$ мм, $z_3 = 26.5$ мм, $z_4 = 27.7$ мм.
  - Все расстояния строго удовлетворяют критерию Найквиста-Шеннона ($z \ge z_{\text{crit}} = 24.06$ мм), исключая элайзинг.
  - Автоматическая нормировка модулей амплитуд $|K|$ к максимуму $1.0$ в каждой плоскости.
- **Составная функция потерь (Composite Loss)**:
  $$\mathcal{L} = \mathcal{L}_1 + (1 - \text{SSIM}) + (1 - \text{PCC})$$
  Оптимизирует одновременно фотометрическую точность ($L_1$), структурную четкость (SSIM) и корреляцию профилей интенсивности (коэффициент Пирсона).
- **Сверхвысокое быстродействие**:
  - Чистое время инференса модели: **< 5 мс** (<5 ms) на GPU (в тесте 2.65 мс).
  - Это на **2–3 порядка быстрее** классического итерационного алгоритма Герчберга-Сэкстона (GS / WGS), требующего сотен итераций с прямыми и обратными БПФ.

## 4. Локальная установка и запуск

### 4.1. Системные требования
- **ОС**: Windows 10/11, Ubuntu 20.04/22.04 или macOS.
- **Python**: версия 3.10, 3.11 или 3.12.
- **CUDA** (опционально): NVIDIA GPU с CUDA 11.8+ / 12.x для ускорения вычислений.

### 4.2. Создание виртуального окружения и установка
```powershell
# Создание виртуального окружения
python -m venv .venv

# Активация виртуального окружения:

.\.venv\Scripts\Activate.ps1
# В Linux / macOS:
# source .venv/bin/activate

# Обновление pip и установка зависимостей
pip install --upgrade pip
pip install -r requirements.txt
```

## 5. Использование CLI инференса (`src/infer.py`)

Скрипт `src/infer.py` поддерживает два взаимозаменяемых режима подачи входных данных:
1. Каталог с 4 изображениями (`--input_dir`).
2. Прямое перечисление 4 файлов плоскостей (`--inputs`).

Все входные изображения автоматически масштабируются и конвертируются в формат **128x128 8-bit grayscale**. Выходной файл фазового ДОЭ сохраняется в формате **128x128 8-bit grayscale PNG** (где значение 0 соответствует фазе $-\pi$, а 255 соответствует $+\pi$).

### 5.1. Инференс из каталога
```powershell
python src/infer.py --input_dir "path/to/group_folder" --output "doe.png"
```

### 5.2. Инференс с явным указанием 4 файлов плоскостей
```powershell
python src/infer.py --inputs plane_1.png plane_2.png plane_3.png plane_4.png --output "doe.png"
```

### 5.3. Инференс с физической валидацией (`--eval`)
Флаг `--eval` рассчитывает дифракцию Френеля для полученного ДОЭ на расстояниях $z_1..z_4$, нормирует модули $|K|$ к 1.0 и выводит метрики SSIM и Pearson CC относительно целевых плоскостей:
```powershell
python src/infer.py --input_dir "path/to/test_group" --output "doe.png" --eval
```

### 5.4. Дополнительные параметры CLI
```text
--input_dir PATH      Путь к директории с 4 изображениями осевых плоскостей
--inputs P1 P2 P3 P4  Явные пути к 4 изображениям плоскостей (z1, z2, z3, z4)
--output PATH         Путь для сохранения фазового ДОЭ (по умолчанию: doe.png)
--weights PATH        Путь к весам модели (по умолчанию: doe_network.pth)
--device {auto,cuda,cpu}
                      Выбор вычислительного устройства (по умолчанию: auto)
--eval                Вычислить дифракцию Френеля и вывести SSIM и Pearson CC
```

## 6. Запуск в Docker-контейнере

Контейнер подготовлен на базе официального PyTorch образа `pytorch/pytorch:2.2.0-cuda12.1-cudnn8-runtime` и работает как на **CPU**, так и на **GPU** с поддержкой NVIDIA Container Toolkit.

### 6.1. Сборка Docker-образа
```bash
docker build -t photonics-doe .
```

### 6.2. Запуск инференса на CPU
Передайте каталог с изображениями через том `-v`:
```bash
docker run --rm -v "$(pwd)/data:/data" photonics-doe \
    --input_dir /data/group_000 \
    --output /data/doe.png
```

### 6.3. Запуск инференса на GPU (NVIDIA Container Toolkit)
```bash
docker run --rm --gpus all -v "$(pwd)/data:/data" photonics-doe \
    --input_dir /data/group_000 \
    --output /data/doe.png \
    --eval
```

### 6.4. Запуск с явным списком файлов
```bash
docker run --rm -v "$(pwd)/data:/data" photonics-doe \
    --inputs /data/p1.png /data/p2.png /data/p3.png /data/p4.png \
    --output /data/doe.png
```
