# Нейросетевой расчет фазового ДОЭ для многоплоскостного формирования волнового фронта

Программный комплекс на базе глубокой гибридной архитектуры **ResAttention U-Net** с частотными операторными слоями (**Fourier Neural Operator / Spectral Convolutions**) и дифференцируемого физического слоя **дифракции Френеля** для сверхбыстрого и высокоточного синтеза фазового профиля дифракционного оптического элемента (ДОЭ), восстанавливающего заданные оптические распределения одновременно в 4 осевых плоскостях.

---

## 1. Физическая модель и оптическая схема

Расчет дифракции света основан на скалярной теории волновой оптики в приближении Френеля с использованием одного быстрого преобразования Фурье (Single-FFT Fresnel):

$$U(x, y, z) = \frac{e^{i k z}}{i \lambda z} e^{i \frac{k}{2z}(x^2 + y^2)} \iint U_0(\xi, \eta) e^{i \frac{k}{2z}(\xi^2 + \eta^2)} e^{-i \frac{2\pi}{\lambda z}(x\xi + y\eta)} d\xi d\eta$$

- **Длина волны излучения**: $\lambda = 532$ нм (зеленый спектр).
- **Разрешение сетки ДОЭ**: $128 \times 128$ пикселей.
- **Шаг дискретизации (размер пикселя ПВМС / SLM)**: $\Delta u = 10$ мкм (апертура $L = 1.28$ мм).
- **Осевые расстояния плоскостей наблюдения**:
  - Плоскость 1: $z_1 = 24.1$ мм
  - Плоскость 2: $z_2 = 25.3$ мм
  - Плоскость 3: $z_3 = 26.5$ мм
  - Плоскость 4: $z_4 = 27.7$ мм
- **Критерий Найквиста-Шеннона**:
  $$z_{\text{crit}} = \frac{N \cdot (\Delta u)^2}{\lambda} = \frac{128 \cdot (10 \cdot 10^{-6})^2}{532 \cdot 10^{-9}} \approx 24.060\text{ мм}$$
  Все плоскости ($z_1 \ge 24.1$ мм) строго удовлетворяют критерию выборки ($z \ge z_{\text{crit}}$), что гарантирует математическое отсутствие фазового элайзинга в спектральной области.
- **Нормировка амплитуды**: Модуль комплексной амплитуды волнового фронта $|K|$ в каждой плоскости строго нормируется на свой локальный максимум ($\max = 1.0$), обеспечивая инвариантность к абсолютной мощности лазера.

## 2. Архитектура нейросети (ResAttention U-Net + FNO)

Модель оптимизирована для решения некорректной обратной задачи фазового поиска и превосходит классические сверточные архитектуры за счет нелокального пространственно-частотного моделирования:

- **Параметры**: 8.42 млн параметров.
- **Вход**: 4-канальный тензор целевых амплитуд `[B, 4, 128, 128]`, соответствующий распределениям в плоскостях $z_1, z_2, z_3, z_4$.
- **Выход**: 1-канальный фазовый профиль ДОЭ `[B, 1, 128, 128]` с проекцией $\tanh(x) \cdot \pi$, гарантирующей строгие физические границы фазовой модуляции $[-\pi, +\pi]$.
- **Резидуальные сверточные блоки (Residual Blocks)**: Устраняют затухание градиентов при глубоком сквозном обучении через физический слой распространения.
- **Механизм пространственного внимания (Attention Gates)**: Фильтрует взаимные помехи (cross-talk) между плоскостями на skip-connections, концентрируя отклик на контурах и интерференционных дифракционных полосах.
- **Спектральный блок Фурье (SpectralConv2d / FNO)**: Выполняет 2D-преобразование Фурье в латентном пространстве боттлнека ($8 \times 8$), обучая глобальные моды волновода с неограниченным эффективным рецептивным полем ($RF \ge 128 \times 128$).

---

## 3. Функция потерь (Composite Loss V3)

Обучение выполняется сквозным методом через дифференцируемый модуль дифракции Френеля с многокомпонентной оптимизацией:

$$\mathcal{L} = w_{\text{pcc}} \cdot (1 - \text{PCC}) + w_{\text{ssim}} \cdot (1 - \text{SSIM}) + w_{\text{ffl}} \cdot \mathcal{L}_{\text{FFL}} + w_{\text{tv}} \cdot \mathcal{L}_{\text{TV}}$$

1. **Pearson Correlation Coefficient Loss ($w_{\text{pcc}} = 4.0$)**:
   $$\text{PCC}(I, T) = \frac{\sum (I - \bar{I})(T - \bar{T})}{\sqrt{\sum (I - \bar{I})^2 \sum (T - \bar{T})^2}}$$
   Обеспечивает масштабную и контрастную инвариантность восстановления формы волнового фронта.
2. **Structural Similarity Loss ($w_{\text{ssim}} = 1.2$)**:
   Сохраняет границы объектов, градиенты яркости и тонкие структурные детали.
3. **Focal Frequency Loss ($\mathcal{L}_{\text{FFL}}$)**:
   Динамически взвешивает трудновосстановимые высокочастотные гармоники в 2D Фурье-спектре интенсивности.
4. **Phase Total Variation Regularization ($\mathcal{L}_{\text{TV}}$)**:
   Подавляет паразитный фазовый шум и предотвращает появление высокочастотных спекл-артефактов на синтезируемом ДОЭ.

## 6. Использование CLI инференса (`src/infer.py`)

Инференс поддерживает два режима подачи целевых оптических распределений:

### 6.1. Подача через директорию группы
Каталог должен содержать 4 изображения (поддерживаются форматы PNG, JPG, BMP):
```powershell
python src/infer.py --input_dir "path/to/group_folder" --output "doe.png"
```

### 6.2. Подача через явный список файлов 4 плоскостей
```powershell
python src/infer.py --inputs plane_1.png plane_2.png plane_3.png plane_4.png --output "doe.png"
```

### 6.3. Инференс с физической валидацией (`--eval`)
Флаг `--eval` рассчитывает дифракцию Френеля для синтезированного ДОЭ на расстояниях $z_1..z_4$, нормирует модули $|K|$ к 1.0 и выводит метрики SSIM и Pearson CC относительно целевых плоскостей:
```powershell
python src/infer.py --input_dir "path/to/group_folder" --output "doe.png" --eval
```

### 6.4. Параметры командной строки
```text
--input_dir PATH      Путь к директории с 4 изображениями осевых плоскостей
--inputs P1 P2 P3 P4  Явные пути к 4 изображениям плоскостей (z1, z2, z3, z4)
--output PATH         Путь для сохранения фазового ДОЭ (по умолчанию: doe.png)
--weights PATH        Путь к файлу весов (по умолчанию: doe_network.pth)
--device {auto,cuda,cpu}
                      Выбор вычислительного устройства (по умолчанию: auto)
--eval                Вычислить дифракцию Френеля и вывести SSIM и Pearson CC
```

Формат квантования выходного файла ДОЭ: 8-битный grayscale PNG ($128 \times 128$), где значение 0 соответствует фазе $-\pi$, а 255 соответствует $+\pi$:
$$\text{Pixel} = \left\lfloor \frac{\varphi + \pi}{2\pi} \cdot 255 \right\rceil$$

## 7. Воспроизведение в Docker-контейнере

Контейнер подготовлен на базе официального PyTorch образа `pytorch/pytorch:2.2.0-cuda12.1-cudnn8-runtime` с поддержкой CPU и GPU (NVIDIA Container Toolkit).

### 7.1. Сборка образа
```bash
docker build -t photonics-doe .
```

### 7.2. Запуск на GPU
```bash
docker run --rm --gpus all -v "$(pwd)/data:/data" photonics-doe \
    --input_dir /data/group_000 \
    --output /data/doe.png \
    --eval
```

### 7.3. Запуск на CPU
```bash
docker run --rm -v "$(pwd)/data:/data" photonics-doe \
    --input_dir /data/group_000 \
    --output /data/doe.png
```
