# Сводный отчет результатов тестирования и валидации модели ДОЭ

## 1. Executive Summary

Выполнена комплексная модернизация нейросетевого метода расчета фазовых дифракционных оптических элементов (ДОЭ) для многоплоскостного восстановления волнового фронта:
- **Архитектура**: исходная примитивная 2-слойная сверточная сеть (39 361 параметр, рецептивное поле всего 5x5 пикселей) заменена на глубокую **U-Net** (7 849 889 параметров) с 4 стадиями сжатия до боттлнека 8x8 пикселей, глобальным рецептивным полем (RF >= 128x128), билинейным декодером со skip-connections конкатенацией и проекцией в фазу строго в диапазоне `[-pi, +pi]` (`tanh(x) * pi`).
- **Физическая модель**: внедрен оптимизированный дифференцируемый слой дифракции Френеля с одним БПФ (`Single-FFT Fresnel`), предрассчитанными комплексными буферами квадратичной фазы чирпа и строгой нормировкой модулей комплексных амплитуд `|K|` к максимуму `1.0` в каждой плоскости.
- **Функция потерь**: реализован сквозной дифференцируемый составной критерий потерь `L = L1 + (1 - SSIM) + (1 - Pearson CC)`, оптимизирующий фотометрическую точность, структурную контрастность и корреляцию Пирсона одновременно по всем 4 осевым плоскостям.
- **Аугментация датасета**: разработан генератор динамических ортогональных групп из 4 независимых изображений (`cross-image grouping`) на пуле из 40 092 патчей DIV2K и генерацией на лету контрастных геометрических масок (буквы, цифры, концентрические кольца, кресты) с вероятностью p=0.3.
- **Обучение**: модель обучена на GPU (NVIDIA GeForce RTX 4060) с оптимизатором AdamW и CosineAnnealingLR до полной устойчивой сходимости (25 эпох).

## 3. Физические параметры оптической системы дифракции

- **Длина волны лазерного излучения ($\lambda$)**: `532.0 нм` (532 нм, зеленый спектр).
- **Линейный шаг пикселя ПВМС ($\Delta u$)**: `10.0 мкм` (10 мкм).
- **Разрешение сетки ДОЭ**: `128 x 128` пикселей (апертура L = 1.28 мм).
- **Осевые расстояния фокусировки плоскостей**: `z1 = 24.1 мм`, `z2 = 25.3 мм`, `z3 = 26.5 мм`, `z4 = 27.7 мм`.
- **Критическое расстояние Найквиста-Шеннона**: `z_crit = N * (delta_u)^2 / lambda = 24.060 мм`.
  Все 4 плоскости удовлетворяют критерию `z >= z_crit`, гарантируя отсутствие спектрального фазового элайзинга при расчете дифракции Френеля с одним БПФ.
- **Нормировка амплитуд**: каждый восстановленный модуль амплитуды `|K|` перед вычислением метрик и экспортом нормирован на свой максимум (максимум строго равен `1.0`), в полном соответствии с правилами жюри.
